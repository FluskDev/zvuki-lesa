# Hero Carousel — Design

## Концепция и видение

Слайдер для Hero секции с автоматической сменой слайдов и поддержкой drag-свайпа. Простая, надёжная реализация на базе Embla Carousel.

## Структура

**Компонент:** `HeroCarousel`
**Расположение:** `src/components/HeroCarousel/`

**Пропсы:**
- `slides: string[]` — массив URL изображений
- `autoplayInterval?: number` — интервал автопрокрутки в мс (по умолчанию 6000)

**Внутреннее состояние:**
- `selectedIndex` — индекс текущего слайда
- `emblaApi` — ref на Embla API

## Поведение

- **Автопрокрутка:** каждые 6 сек переключает на следующий слайд
- **Пауза автопрокрутки:** при drag-прокрутке пользователем
- **Drag-свайп:** включён, разрешено тащить в обе стороны
- **Цикличность:** после последнего слайда возврат к первому

## UI

- **Изображения:** `object-fit: cover`, на всю ширину/высоту контейнера
- **Overlay:** градиент `rgba(0,0,0,0.4)` → `rgba(0,0,0,0.2)` → `rgba(0,0,0,0.6)`
- **Индикаторы:** круглые точки внизу по центру, 24px, светлые с прозрачностью, активная — белая заполненная
- **Z-index:** контент Hero выше карусели
